## Introduction to Machine Learning

In computer science, AI and ML are often used interchangeably. However, they represent different concepts. *Artificial Intelligence* (AI) is a broad field that is focused on developing intelligent systems that are capable of performing tasks that typically require human intelligence. These tasks might include: NLP, decision making, problem solving and adaptive learning. AI systems are designed to exhibit cognitive abilities such as reasoning, perception and problem-solving.

*Machine learning* is a subfield of AI that focuses on enabling systems to learn from previously collected data to improve their own performance without human intervention. ML algorithms use statistical techniques to identify patterns, trends and anomalies within data which should allow the system to make predictions or decisions  on new input data. ML is broadly categorised into:

- **Supervised Learning**: The algorithm learns from labelled data, with an explicit "answer" to each categorisation.

- **Unsupervised Learning**: Where the algorithm learns from unlabelled data.

- **Reinforcement Learning**: Where the algorithm learns through trial and error by interacting with an environment for rewards or penalties.

*Deep learning* (DL) is a subfield of ML  that uses neural networks to learn and extract features from complex data. These systems aim to automatically identify patterns and representations which makes them particularly useful for high-dimensional or unstructured data. DL models have some key characteristics:

- **Hierarchical feature learning:** DL models learn data representations where each layer captures increasingly abstract features.

- **End-to-End Learning**: DL models can directly map raw input data to desired outputs.

- **Scalability**: DL models scale well with large datasets.

Some common types of neural networks used in DL are:

- **Convolutional Neural Networks (CNNs)**: These are specialised for image and video data. They use convolutional layers to detect patterns.

- **Recurrent Neural Networks (RNNs)**: These are designed for sequential data like text and speech. They have loops that allow information to persist across time steps.

- **Transformers**: These are particularly effective for NLP tasks. They use self-attention mechanisms to handle long-range dependencies.
