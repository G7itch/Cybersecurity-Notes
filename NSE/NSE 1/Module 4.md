# Malware

Malware is short for malicious software. Malware is created to achieve various tasks which compromise the CIA triad of data.

### Malware Types

Malware can change a computers behaviour without the knowledge of the user. There are key behavioural actions that may be potential indicators of a malware attack.

A computer virus is a type of malware to alter the way a computer operates and spreads between computers. Viruses must be invoked by a user and must be attached to legitimate applications. They are also designed to spread the infection to other programs or devices.

### Viruses

**Resident**: Virus that infects apps when opened.

**Non-resident**: Virus that infects executable files when they are not running.

**Multipartite**: Virus that infects many computers, often stays in memory.

**Direct action**: Virus that access the main memory and infects all applications and files.

**Browser hijacker**: Manually changes settings for a browser.

**Overwrite**: Can delete and replace files data with its own content or code.

**Web scripting**: Virus that attacks web browser security to allow for injection of malicious code.

**File infector**: Overwrites files when opened.

**Network**: Virus that cripples networks and spreads to devices connected to the computer network.

**Boot sector**: Virus that targets MBR and injects into the hard disk partition.

### Other Malware

**Worm**: Does not need a host and is designed to replicate.

**Rootkit**: Hides in the kernel level to avoid detection.

**DLL injection**: Replaces legitimate DLLs with malicious ones.

**Driver manipulation**: Changes or replaces driver software.

**Keylogger**: Records keystrokes on a computer.

**Spyware**: Malware designed to spy on users. Collects personal information and data without consent.

**Potentially unwanted program (PUP)**: Unwanted programs that the user may have unknowingly downloaded.

**Adware**: Hides on a device and displays adverts.

**Dialler**: Malware that uses dialling features to run phone bills.

**Adversarial artificial intelligence**: Malicious input designed to confuse neural networks.

**Ransomware**: Encrypts information on a computer, restored only after paying a ransom.

**Trojan horse**: A virus designed to look like something it is not.

**Dropper**: A trojan horse designed to install malware onto a computer.

**Rogueware/Scareware**: Misleads a user into believing malware is on their computer and prompts them to pay or download more malware to fix the issue.

**Botnet malware**: Malware that infects a host through a C2 server.

**Cryptojacking**: The illegal use of a users  computing resources to mine cryptocurrency.

### Malware Attack Vectors

An attack vector is a method that a threat actor uses to access of inhibit a network, system or facility. There are methods of attacks and categories of attacks. Attack vectors need 3 things:

1. Vulnerability

2. Method

3. Pathway

An attack surface represents the total number of entry points that the vector creates the gain unauthorised access. When it comes to malware we have attack vectors such as watering hole attacks. In this case the vulnerability is the user, the pathways is the social media site and the mechanism is the malware.

Bots are also called zombies. Threat actors can control bots via a C2 server and the collection of all bots is called a botnet.

**Backdoor**: An unauthorised way of gaining access to a computer system.

**Logic bomb**: Piece of malicious code that will only execute under certain conditions.

**Dropper**: Program that extracts files, typically malicious, to a machine.

**Downloader**: A trojan horse that installs on a computer and uses the internet to fetch more malware.

**Code injection**: Code is injected into an application to change how it runs.
