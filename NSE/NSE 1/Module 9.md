# Secure Data and Applications

### Data Protection

Data protection include safeguards for data at rest, data in use and data in transit. It ensures the CIA triad of data as well as non-repudiation. Data security involves:

- Maintaining the integrity of digital and physical assets.

- Ensuring the integrity of data throughout the entire lifecycle.

- Properly authorizing use and access.

- Data sovereignty.

- Data privacy.

There are different types of data that needs to be secured:

- **Controlled Unclassified Information (CUI)**: Government created or owned.

- **Personally identifiable information (PII)**

- **Protected Health Information (PHI)**

- **Payment Card Industry (PCI)**

- **Sensitive Institutional Data**

- **IT Security Information**

- **Export Control Records**

- **Student Education Records**

Data has some risks associated with it. These include data exposure and infection by malware. Threats can originate internally or externally. Risks are present throughout the data lifecycle:

1. *Creation*

2. *Storage*

3. *Usage*

4. *Archiving*

5. *Destruction*

DLP helps organisations to identify sensitive information. They can then prevent accidental sharing of data, audit and monitor data movement. DLP should be implemented on the endpoint, at the network level, in the storage place and in the cloud.

### Data Privacy

Data privacy refers to the proper handling of personal data and other sensitive data types. Data privacy is important because data is valuable and individuals need to have control over their data. Privacy risk is the likelihood of experiencing problems resulting from data processing. Data breaches can be very costly.

To protect data, organisations must:

- Identify sensitive data.

- Identify authorised roles, users and policies.

- Collect and report data asset compromise.

- Develop response procedures to breaches.

- Implement cryptographic measures.

More generally, organisations must obey the laws in their operating regions. This could include GDPR, ISO 127001, SOC2, PCI DSS, HIPAA and more.

### Secure Email Gateway

Unsolicited and irrelevant email sent to many recipients is called spam. Phishing is a social engineering attack that uses spam, primarily to cause data breaches. Secure Email Gateway (SEG) is a technology designed to protect organisations from email threats. SEG can filter content and implement DLP. Spam filters can be used to eliminate harmful content from spam by reducing the amount of emails that end up in the users inboxes.

SEG can also support authentication and identity verification. Some SEG has malware filters and encryption capabilities.

The sender policy framework (SPF) verifies sending server IP addresses. This can prevent email spoofing and sender address forgery.

### WAF

A web application firewall (WAF) monitors HTTP/HTTPS traffic and can block malicious web traffic. Web application firewalls sit behind web applications and in front of the server. WAF cannot rely on traditional edge firewall methods.

The first generation of WAFs used block lists. Second generation WAFs could learn application behaviour in order to evaluate if access attempts were normal or irregular.

### Content Filters

Content filtering is the process to screen or restrict access to suspicious items. It is often built in to web applications. Content filters are used in different ways to block access to different materials. Common filters include search engine filters, email filters, DNS filters and web filters.

Content filters can block access to sites known to contain malware. They can also prevent access before a web app triggers a malware download.

### Application Hardening Techniques

It is easy to install large amounts of apps onto devices in the modern day. These apps can contain malicious code even if it is believed that the source is trustworthy. Application hardening is required to minimise vulnerabilities. In organisations, they encourage users to use specific, company approved tools. The organisations IT team should also train employees on security behaviours.

Organisations should also use proxies to boost data privacy and free up network resources. Patch management systems should exist on a network to help with automatic updates.

Application hardening can improve application performance.
